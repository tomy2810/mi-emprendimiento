# Tecnologías del proyecto — YIZU
> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Maquetación web y diseño visual sin frameworks ni gestores de contenido. |
| Versionado | Git y GitHub | Control de versiones y alojamiento del repositorio del proyecto. |
| Publicación | GitHub Pages | Despliegue y publicación en línea del sitio web. |
| Diseño | Whimsical | Creación de moodboards, componentes y wireframes. |
| Diseño | Google Stitch | Creación e interacción del prototipo navegable. |
| IA | ChatGPT / Claude | Asistencia en la estructuración de contenidos y generación de código. |
| Editor | VS Code / Claude Code | Editor de código fuente para el desarrollo web. |


## Qué es funcional y qué es prototipo

| Funcionalidad | Estado en esta versión |
|---|---|
| Catálogo de prendas YIZU | Funcional |
| Vista de detalle de productos | Funcional |
| Carrito de compras visual | Prototipo visual |
| Proceso de pago (Checkout) | Prototipo visual |
| Formulario de contacto | Prototipo visual |

## Integraciones para una versión real
- Pasarela de pago en línea (Webpay, Flow o Stripe).
- Sistema de despacho e integración logística (Starken, Chilexpress o Blue Express).
- Botón de contacto directo por WhatsApp para soporte e información.
- Integración con Instagram Shop / Meta Pixel para redirección e interacción social.


## Restricciones
- **Recursos de desarrollo:** El proyecto utilizará herramientas y recursos gratuitos, evitando servicios que requieran suscripciones o pagos adicionales.
- **Alcance técnico:** El proyecto se limitará a una interfaz web sin backend ni base de datos funcional.
- **Pagos y envíos:** El carrito, el checkout y los cálculos de despacho serán simulaciones visuales, sin transacciones reales.
- **Formulario de contacto:** Se presentará como prototipo visual, sin envío ni almacenamiento de datos.
- **Dispositivos:** El diseño deberá adaptarse a pantallas móviles y de escritorio, manteniendo una navegación clara y accesible.
